# Проверка замечаний IPC PR 2740

Проверены исходники отдельной ветки `ipc-paradise-upstream`, исходный HEAD
`4685c1aa2d7aa6c1a80222fda0a05c44dc996969`. Комментарии ботов использовались
как гипотезы; ответы в GitHub не отправлялись.

| Замечание | Результат проверки |
| --- | --- |
| `mob_insert()` возвращает `null` | Не подтверждено: `code/modules/surgery/organs/organ_movement.dm` явно возвращает `TRUE` после `on_mob_insert()`. Совместимость проверяется до замены прежнего органа. |
| Вид IPC — общий singleton, состояние эмоций смешивается | Не подтверждено: `code/datums/dna/dna.dm`, `set_species()` создаёт `new mrace`; `dna/New()` также создаёт собственный вид. Списки добавленных и удалённых verbs принадлежат этому экземпляру. |
| `apc.cell.charge()` — отсутствующий proc | Не подтверждено: `code/modules/power/power_store.dm` определяет `charge()` и возвращает поле `charge`. Существующий `ipc_apc_charging` использует настоящий APC и проверяет расход энергии. |
| При инициализации IPC-конечности отсутствует DNA | Не подтверждено: `human/Initialize()` вызывает `create_dna()` до `create_fresh_body()`. При удалении carbon его bodyparts уничтожаются до DNA. Новая произвольная защита не добавлена. |
| `istype(brain_loc)` пропускает MMI | Не подтверждено: локальная переменная объявлена `/obj/item/organ/brain`; однопараметрический `istype()` проверяет этот объявленный тип. `ipc_positronic_mmi` уже перемещает и core, и MMI через nullspace. |
| Отсоединённая голова должна сохранять светящийся экран | Предложение о поведении: текущая голова без владельца отключает питаемый дисплей, сохраняя физическую антенну и настройки. В этом исправлении правило питания не менялось. |
| Извлечение мозга должно удалять радиацию | Отклонено: отсутствие мозга возвращает `null`, а не нулевой урон. Компонент намеренно сохраняется на корпусе; `ipc_radiation_timing_and_repair` проверяет извлечение, повторную установку и окончательную очистку после ремонта. |
| Ограничить гарантированную хирургию только `OPERATION_MECHANIC` | Изменение ранее согласованного поведения: текущий перенос гарантирует успех допустимых операций над IPC. Экспериментальное вскрытие само по себе не доказывает дефект этого правила. |
| Запретить microbattery в органическом человеке | Изменение правил трансплантации, не ошибка API. Новое ограничение совместимости в этот технический аудит не добавлено. |
| Перенести переводы из `public/ru_names` | Отклонено: актуальные инструкции дерева используют именно `modular_bandastation/translations/public/ru_names`; старое указание бота не соответствует сборке. |
| IPC runner может пропустить ошибки | Исправлено: ненулевой выход DD, отсутствие любого из трёх логов, сырые runtimes и отсутствие screenshot-группы проваливают запуск. Discovery поддерживает вложенные типы; найдены все 75 исходных IPC `Run()` и два новых regression-теста utensils. Добавлен `focus_only/invalid_emissives`. |
| Pinned asset converter читает локально изменённые исходники | Исправлено: до чтения ресурсов и записи результатов требуется чистый checkout, включая staged, unstaged и untracked файлы. `test_convert_assets.py` проверяет отказ до записи и разрешение чистого pinned checkout. |
| Ложка с culinary не расходуется, вилка не даёт вкуса | Подтверждено: `trans_to()` отказывается переносить реагенты иммунному получателю и оставляет ложку наполненной. Ложка теперь вызывает существующий `consume_flavor()`, а вилка — `taste_list()` перед очисткой уже снятой с омлета порции. Два regression-теста используют настоящие fork/spoon/ladle и проверяют самостоятельную еду, кормление, точный расход и прерывание при потере процессора. |
| Production `rand()` в проверке останков портит RNG тестов | Без фактического провала не подтверждено: тест намеренно проходит настоящий путь появления останков. Случайное визуальное смещение не влияет на проверяемый тип останков. |

Изменения игрового баланса, новые ограничения трансплантации и перенос переводов
не выполнялись. Полная игровая проверка фиксируется отдельно после фактического запуска.
