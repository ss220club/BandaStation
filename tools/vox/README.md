# Проверка воксов

Из корня репозитория сначала собрать игровые ресурсы, затем запустить проверки:

```powershell
tools/build/build.bat
tools/vox/test-vox.ps1
```

По умолчанию скрипт ищет BYOND **516.1685** в `DM_EXE`, `PATH` и стандартных
каталогах установки. Другую установку можно выбрать явно:

```powershell
tools/vox/test-vox.ps1 -ByondBin 'C:\Program Files (x86)\BYOND\bin' -IncludeHumanoidScreenshots
```

Скрипт обнаруживает все тесты с `Run()` в `vox*.dm` и `ipc*.dm` внутри
`modular_bandastation/species/code/tests`, включая вложенные типы. Дополнительно
запускаются проверки выбора и смены расы, органов, несовместимой одежды,
сохранения предметов в руках, исследований и состояний предметных спрайтов,
одежды и предметов в обеих руках. `-IncludeHumanoidScreenshots` добавляет
существующий набор изображений всех гуманоидных рас.

Игра запускается в отдельной `tmp/vox-test-*` на минимальной runtime-карте.
В эту папку сохраняются список выбранных тестов, сборка, результаты, логи и
изображения. Успех требует результата каждого выбранного теста, нулевого кода
завершения сервера, `clean_run.lk` со значением `Success!`, отсутствия runtime
в `dd.log`, `runtime.log.json` и `console.log`, а также успешного сравнения PNG.
Отсутствующие логи и изображения выбранного screenshot-теста считаются ошибкой.
Таймаут можно увеличить параметром `-TimeoutSeconds` (по умолчанию 300 секунд).

Новые изображения надо осмотреть до добавления эталонов в
`code/modules/unit_tests/screenshots`. Первый запуск без эталона провалится и
сохранит кандидат в папке прогона; после принятия эталонов нужен повторный запуск.
Скрипт не добавляет эталоны автоматически и не меняет рабочую конфигурацию сервера.

Этот прогон проверяет перечисленные сценарии на минимальной карте. Полный CI
на станциях и проверка в игровом клиенте выполняются отдельно.

Строгая проверка 32 импортированных файлов DMI:

```powershell
python tools/vox/check_assets.py
```

Она проверяет полную загрузку PNG, размеры клеток, уникальность состояний,
число направлений и кадров, задержки анимаций и точные исходные Git blob hashes
для файлов без адаптации. Если подходящего состояния нет, код выбирает стандартный файл предмета
вместо невидимого спрайта.
Такой fallback сохраняет видимость, но сам по себе не доказывает подгонку одежды.

`source-assets.json` фиксирует непосредственный источник — BandaStation PR #2682,
ревизию `319e91d353a34b90263bda08b5409ca3d85e3dbd` и хэши исходных изображений.
После скачивания этих файлов с исходными относительными путями адаптация повторяется:

```powershell
python tools/vox/adapt_assets.py --source tmp/vox-source/assets
```

Скрипт объединяет подходящие head/helmet states, переименовывает варианты касок
под TG, удаляет повторные human-mask states и добавляет недостающие состояния ног.
Кадры и пиксели исходных состояний сохраняются. Источники и лицензия изображений
перечислены в `icons/bandastation/mob/species/vox/attributions.txt`.
