# Профессии подписчиков

В `config/game_options.txt` включите `DONOR_JOBS_ENABLED` для 16 новых профессий. Флаги `DONOR_JOBS_ENABLED` и `DONOR_PRISONER_GATE` по умолчанию выключены; после изменения нужен перезапуск. Настройки вакансий задаются штатным `config/jobconfig.toml` и конфигурацией карты.

| Минимальный тир | Профессии |
|---|---|
| T1 | Безработный, Музыкант, Актёр, Официант |
| T2 | Послушник, Охранник сервиса |
| T3 | Сервис-администратор, Турист ТСФ, Турист КССП, Торговец |
| T4 | Клоун СБ, Мигрант, Банкир |
| T5 | VIP-гость корпорации, Представитель ТСФ, Представитель КССП |

Более высокий тир открывает также профессии нижних тиров.

Заключённый не требует подписки и находится среди обычных профессий. Отдельный `DONOR_PRISONER_GATE`, несмотря на сохранённое имя, включает его варианты и расширения: 3 места на старте, общий лимит — 5. Его лендмарки, проверки безопасного появления, преступление и запись manifest сохраняются. Этот флаг не зависит от `DONOR_JOBS_ENABLED`.

Вкладка «Подписка» группирует роли по минимальному тиру. В строке доступны приоритет, вариант и профиль персонажа. При первоначальном запуске старые назначения профилей не переносятся; новые сохраняются в `pref_job_slots`.

Точки входа новых ролей объявлены в `code/landmarks/`; их размещение на картах выполняется отдельно. При включённом `DONOR_PRISONER_GATE` без подходящей точки Prisoner остаётся недоступен.
