# Профессии подписчиков

В `config/game_options.txt` включите `DONOR_JOBS_ENABLED` для 22 новых профессий. Отдельный `DONOR_PRISONER_GATE` включает варианты Prisoner: 3 места на старте, общий лимит — 5. Оба флага по умолчанию выключены; после изменения нужен перезапуск. Настройки вакансий задаются штатным `config/jobconfig.toml` и конфигурацией карты.

Вкладка «Подписка» группирует роли по минимальному тиру. В строке доступны приоритет, вариант и профиль персонажа. При первоначальном запуске старые назначения профилей не переносятся; новые сохраняются в `pref_job_slots`.

Точки входа новых ролей объявлены в `code/landmarks/`; их размещение на картах выполняется отдельно. Без подходящей точки Prisoner остаётся недоступен.
