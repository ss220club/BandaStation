sequence
/datum/bt_node/composite/sequence

Sequence node: ticks children in order. Returns BT_FAILURE on first child failure. Returns BT_RUNNING on first child returning BT_RUNNING (stops further evaluation). Returns BT_SUCCESS only if all children succeed.

Resumes from the last RUNNING child index rather than restarting from child 1.
