Reproducible adapter: tools/vox/adapt_paradise_assets.py.

Changes in PrimeDream: selected states are grouped by worn slot and replacement
policy, and equivalent item states receive TG-compatible names. Source pixels,
colours, 32x32 cell anchors, direction order and animation metadata are preserved.
These overlays fit the existing Nova Vox body; no Paradise body parts are used.
Donator, personal, prime_only, goonstation and tgmc assets are excluded.

The auxiliary carved_pumpkin-emissive state retains the exact authored lit RGBA
pixels that differ between hardhat1_blumpkin and hardhat0_blumpkin in the pinned
head.dmi: four pixels facing south, two each east/west, none facing north. All
unchanged pixels are transparent. Its recipe is recorded separately from the
wearable mappings; the human pumpkin mask has different eyes and mouth anchors.

Fourteen winter hoods additionally copy 42 opaque border/fabric pixels per
state into previously transparent cells (13 south/north, eight east/west),
closing the contour over the current Vox head ears. Each copy uses the same
source state and direction, with exact coordinates in the named
winterhood_head_coverage transform. All original hood pixels remain unchanged.
