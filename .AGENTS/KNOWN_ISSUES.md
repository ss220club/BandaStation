# Границы инструментов

- Include-инспектор читает текстовые `#include`, не выполняет DM препроцессор. Условия подключения и compile проверяются отдельно.
- Браузерный MCP подтверждает веб-сценарий; полноценную работу BYOND подтверждает отдельный native runtime.
- Установщик и browser launcher рассчитаны на Windows с Microsoft Edge. Зависимости устанавливаются по locks вне Git.
- Доверие к проекту и обновление подключения MCP зависят от клиента. Standalone smoke не подтверждает наличие tools в конкретном чате.
- Task state не обеспечивает блокировки или автоматическое распределение ресурсов между агентами.
- Git hook локален и не защищает от намеренного обхода. Custom hooks/config/cache установщик сохраняет и сам не объединяет.
- Если защитное ПО удаляет runtime-файлы, сначала проверь конкретное событие. SHA256-проверка обнаруживает изменение; `setup-tools.ps1 -Repair` восстанавливает управляемый cache. Не отключай защиту и не добавляй исключения автоматически.
